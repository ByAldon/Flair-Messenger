# Flair Messenger (FM)

Simpel starten:

1. Dubbelklik op `Start-FlairMessenger.bat`.
2. Vul je loginnaam, wachtwoord en loginlocatie in.
3. Vink `Gegevens opslaan` aan als je dit de volgende keer automatisch wilt invullen.

De app bewaart lokale gegevens in de map `data` naast `Start-FlairMessenger.bat`. Je kunt de projectmap dus verplaatsen. De BAT start de messenger zonder zichtbaar CMD-venster; eventuele startfouten komen in `data\launcher.log`.

Flair Messenger gebruikt LibreMetaverse om in te loggen op Second Life. Gebruik je Second Life accountnaam als `Voornaam Achternaam` of `voornaam.achternaam`. Accounts zonder achternaam gebruiken automatisch `Resident`.
