# Flair Messenger (FM)

Simple start:

1. Double-click on `Start-FlairMessenger.bat`.

2. Enter your username, password, and login location.

3. Check `Save details` if you want to fill this in automatically next time.

The app saves local data in the `data` folder next to `Start-FlairMessenger.bat`. You can therefore move the project folder. The BAT starts the messenger without a visible CMD window; any startup errors appear in `data\launcher.log`.

Flair Messenger uses LibreMetaverse to log in to Second Life. Use your Second Life account name as `First Name Last Name` or `firstname.lastname`. Accounts without a last name automatically use `Resident`.
